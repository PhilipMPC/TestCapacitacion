# TestCapacitacion
CATÁLOGO DE INTERVENCIONES DE APRENDIZAJE Y DESARROLLO
Alineado al Modelo de Evaluación de Kirkpatrick
Aplicable para empresas de Retail, Consumo Masivo y Servicios
________________________________________
1. OBJETIVO DEL CATÁLOGO
Este catálogo tiene como finalidad estandarizar los diferentes tipos de intervenciones de aprendizaje que pueden implementarse dentro de una organización, identificando:
•	Definición.
•	Objetivo.
•	Cuándo utilizarla.
•	Duración recomendada.
•	Tipo de habilidad que desarrolla.
•	Nivel de impacto esperado.
•	Nivel de Kirkpatrick asociado.
•	Aplicación dentro de empresas de Retail.
________________________________________
CLASIFICACIÓN GENERAL
Las intervenciones de aprendizaje se agrupan en cuatro grandes categorías:
A. INFORMACIÓN
Objetivo:
Transmitir información.
Impacto esperado:
Conocimiento básico.
Nivel Kirkpatrick predominante:
Nivel 1 y parcialmente Nivel 2. 
________________________________________
B. SENSIBILIZACIÓN
Objetivo:
Generar conciencia, compromiso o interés.
Impacto esperado:
Cambio de percepción.
Nivel Kirkpatrick predominante:
Nivel 1 y Nivel 2. 
________________________________________
C. CAPACITACIÓN
Objetivo:
Desarrollar conocimientos y habilidades.
Impacto esperado:
Aprendizaje y transferencia.
Nivel Kirkpatrick predominante:
Nivel 2 y Nivel 3. 
________________________________________
D. DESARROLLO
Objetivo:
Modificar comportamientos y mejorar desempeño.
Impacto esperado:
Resultados sostenibles.
Nivel Kirkpatrick predominante:
Nivel 3 y Nivel 4.

CONCLUSIÓN 
No todas las intervenciones de aprendizaje buscan el mismo resultado. Una socialización informa; una charla sensibiliza; un curso enseña; un taller desarrolla habilidades; una simulación permite practicar; un OJT genera transferencia inmediata; y estrategias como coaching, mentoring y proyectos especiales buscan transformar comportamientos y producir resultados sostenibles en el negocio.
Desde la perspectiva del Modelo de Kirkpatrick, las intervenciones con mayor impacto en los niveles de Comportamiento (Nivel 3) y Resultados (Nivel 4) son: OJT, Coaching, Mentoring, Simulación, Proyectos Especiales y Blended Learning, mientras que las intervenciones informativas y de sensibilización se concentran principalmente en los niveles de Reacción (Nivel 1) y Aprendizaje (Nivel 2). 
Este catálogo puede considerarse una base maestra inicial para la clasificación de iniciativas de Formación y Desarrollo dentro de organizaciones de Retail.
